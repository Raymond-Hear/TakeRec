# 简录 · TakeRec

> 这是简录的完整使用说明。想先快速了解可以回到 [README](../README.md)。

先保存工程并退出旧版，再打开「简录.app」。支持 macOS 15 及以上，安装包包含 Apple Silicon 和 Intel 两种架构。本机运行验证使用 Apple Silicon 和 macOS 26.4。

## 剪辑工作台

- 成片预览按原画幅显示，播放条贴着画面。下拉预览和时间线之间的分隔柄可增大预览，双击分隔柄可恢复默认。四条基础轨道位于底部，屏幕和人像片段各显示自己的缩略图，播放线贯穿各轨。点人像或声音轨会切到相应设置，工具栏的「设置」可收起右栏。
- 录制准备页在预览上方选画面来源，下方选分辨率，右侧检查摄像头、麦克风电平和系统声音。人像形状、镜像和调光在「人像设置…」，光标和点击记录在「录制选项…」。准备好后点右下方的「开始录制」。
- 点击右上角的版本号，可查看项目仓库与创作者聆风Raymond的联系方式。悬停公众号名称会在右侧显示二维码，点击小二维码图标可以固定显示。

## 清晰度、全屏和人像调光

- 在录制来源下方的「屏幕分辨率」选择 1080p 或 4K，默认 4K。选好来源后会显示来源像素和实际录制像素。两档分别以 1920×1080 和 3840×2160 为上限，竖屏交换长宽，并保留来源比例。「导出 MP4…」可选成片分辨率，实际像素以工程素材为限。
- 选择全屏后，可在分辨率旁关闭「录制顶部菜单栏」。预览和录制会一起裁掉顶部菜单栏区域，实际录制尺寸会随之更新。
- 本机真人摄像头可以单独设置 1080p 或 4K，并按设备支持的模式采集。扫码连接手机时网页请求 1080p，实际输入尺寸取决于手机和网络。录制页的人像设置会显示收到的尺寸。 [Apple 摄像头采集配置](https://developer.apple.com/documentation/avfoundation/avcapturesession/sessionpreset) · [VDO.Ninja 的分辨率说明](https://docs.vdo.ninja/guides/how-do-i-control-bitrate-quality)
- 编辑时点击预览画面或播放条右侧的展开图标进入全屏。全屏沿用播放位置和播放快捷键，可拖进度条，按 `Esc` 或点「退出全屏」回到时间线。「添加焦点」模式下点击画面会添加运镜焦点。
- 真人摄像头开启后，在「人像设置…」展开「人像调光」，可调整曝光、压高光和清晰度。编辑器在「画面 → 人像」里也能调整。设置随工程保存，原始人像分轨保留采集画面。脸部已过曝成纯白时，录制前降低灯的亮度或调整灯的角度，才能保留那部分细节。

## 自定义快捷键

从「简录 → 设置…」进入「快捷键」。录制准备页的键盘图标和编辑页「更多 → 快捷键设置」也能打开。点某项右侧的按键，再按下新组合，例如 `Ctrl+S` 保存或 `Ctrl+K` 分割。按 `Esc` 取消。重复组合会提示已绑定的操作。修改会立即生效并保存在本机，也可以点「恢复默认」。

| 编辑操作 | 默认快捷键 |
| --- | --- |
| 播放或暂停预览 | 空格 |
| 保存工程 | `⌘S` |
| 在播放头处分割当前轨道 | `⌘K` |
| 在播放头处分割所有轨道 | `⇧⌘K` |
| 删除所选片段 | `⌫` |
| 撤销片段操作 | `⌘Z` |
| 重做片段操作 | `⇧⌘Z` |

录制与提词器的快捷键也可以在同一页修改。这组按键在简录运行时可跨 App 使用，提词器显示时可用快捷键翻页。

## 录制前检查

1. 选「单窗口」或「全屏」，点击「选择录制内容…」，在 macOS 选择器中确认。预览就绪后，按 `⌃⇧R`（Control–Shift–R）或点「开始录制」。
2. 开启「摄像头」，从列表选主机位。用「添加机位」选外接摄像头，或在手机扫码连上后选「添加为新机位」。最多可同时录三路，开录前可预览每一路。各路视频独立保存，声音使用录制页选定的音轨。
3. 开启「麦克风」，选择内置、外接或手机网页输入。说话时可看原始输入峰值。可预选 100%、150% 或 200% 增强，编辑预览和导出会应用这项设置。建议用耳机或耳麦，减少外放声串入麦克风。接入设备后可以点「刷新设备」。
4. 开启「系统声音」即可保留独立的系统音轨。麦克风和系统声音同时开启时，「人声优先」默认打开，效果在编辑预览和导出时生效。
5. 在「录制选项…」可选光标样式。「真实系统光标」随画面捕获 macOS 当时显示的形状，例如文字光标和手型。「可编辑样式」可在录后换图样。两种模式都可以独立开启「记录点击与运镜」。
6. 按 `⌃⇧S`（Control–Shift–S）结束录制并进入编辑。简录运行时，切到其他 App 也能用这组快捷键。全屏录制时主窗口会收起，屏幕顶部的简录彩色图标里也有「暂停录制」和「结束录制」。

**用简录的「人像设置… → 人像前置 → 圆形人像」**。macOS 录制菜单的小圆圈属于系统人物前置，开启后 macOS 会把相机画面提前合成进屏幕帧。App 会拦截带叠层标记的帧，预览期间提示关闭系统人物前置，录制期间结束当前录制并保留此前已收到的干净素材。 [Apple 人物前置说明](https://support.apple.com/zh-cn/guide/mac-help/mchlff01c919/mac) · [ScreenCaptureKit 帧标记](https://developer.apple.com/documentation/screencapturekit/scstreamframeinfo/presenteroverlaycontentrect)

## 手机扫码和跟脸面具

- 建议先用 Mac 的摄像头和麦克风，启用时按 macOS 提示授权。需要手机机位时，在录制页点「手机扫码…」，查看权限和隐私说明，再点「生成二维码」连接。用手机浏览器扫码并授权相机和麦克风。看到所需输入就绪后点「使用手机输入」，可以分别选择手机相机或手机麦克风。结束后关闭手机网页即可释放设备。
- 扫码使用第三方 VDO.Ninja 的 HTTPS 页面和信令服务。手机相机与麦克风通常通过加密 WebRTC 直连 Mac，直连失败时可经 TURN 中继。Mac 的屏幕和系统声音由简录在本机采集与保存。 [VDO.Ninja 工作原理](https://docs.vdo.ninja/readme/how-does-it-work) · [VDO.Ninja 隐私说明](https://docs.vdo.ninja/help/privacy-and-security-details/vdo.ninja-privacy-policy)
- 每次生成新的配对 ID 和口令，简录等待首次连接最多五分钟。配对信息放在由手机浏览器解析的 URL 片段中，并关闭网页的连接质量统计。服务仍可能处理 IP 和连接诊断。把二维码留给自己，结束时在手机上关闭网页。 [VDO.Ninja 片段参数](https://docs.vdo.ninja/help/privacy-and-security-details/fragment-url-parameters)
- 在「人像设置… → 人像画面」选择黄色小狗、便便、男生或女生面具。面具贴着摄像头画面里的脸移动和缩放，响应转头、眨眼和张嘴，保留身体和背景。这一版使用原创 2D 面具和 Apple Vision 跟踪。 [Apple 动态拟我表情](https://support.apple.com/zh-cn/111115) · [Apple Vision 面部特征点](https://developer.apple.com/documentation/vision/vndetectfacelandmarksrequest)
- 面具在 Mac 上逐帧合成，人像分轨保存已经盖住脸的画面。检测不到合适的人脸或检测到多张脸时，暂时遮住整个摄像头画面。扫码输入时，手机相机画面实时传到 Mac 再做这一步。
- 手机接收器使用未修改的 VDO.Ninja SDK 1.6.2。MPL-2.0 许可和对应源码随 App 一起打包。 [SDK 固定版本源码](https://github.com/steveseguin/ninjasdk/tree/328965a06fa19cf47c3f01182e9cb1d91f39214e)

## 录制控制条与提词器

- 录制控制条显示相机状态、已录时长和音频电平。按住左侧「录制控制条」手柄可把它拖到其他位置。优先显示麦克风，麦克风关闭时显示启用的系统声音。音频中断、麦克风持续低电平或电平反复偏高时会提示。
- 「暂停」冻结计时，点「继续」接着录。暂停区间从画面、音频和点击时间线中扣除。相机画面中断时会提示并保留已经录到的人像，屏幕和音频继续录制。
- 录前点「提词器…」输入逐字稿。可选手动翻页或自动滚动，速度可从 0.5× 调到 3×。用「浮窗预览」试速度和位置，开录时会从头开始，录制暂停时滚动也会暂停。默认 `⌃⇧←` 和 `⌃⇧→` 翻页或跳一屏，`⌃⇧P` 暂停或继续滚动，`⌃⇧T` 显示或隐藏提词器。快捷键可在简录设置里修改。
- 录制时，控制条默认在录制屏幕底部，提词器在同一屏幕顶部。开启「显示录制控制条」和「开录时显示提词器」即可自动弹出，提词器需要有逐字稿。菜单栏的「找回录制浮窗」可以把它们移回初始位置。
- 控制条下方显示当前可用的快捷键。修改快捷键后，这里的提示会一起更新。
- 单窗口录制时，浮窗独立于所选窗口。全屏浮窗需要 macOS 15.2 或以上。简录先准备两块浮窗，再单独启动按窗口排除的屏幕采集。未就绪时可去授权、改录单窗口，或继续录制并隐藏浮窗。如果 macOS 要求重新启动，退出并打开同一份简录，再选录制画面。菜单栏也提供暂停、继续和结束。 [Apple 采集内容筛选](https://developer.apple.com/documentation/screencapturekit/sccontentfilter)

## 键盘按键展示

录制前开启「保留按键轨」，并在「权限设置」中允许「输入监控」。「录制时显示键帽」控制实时预览和剪辑时的初始显示。即使实时隐藏，开启了按键轨也会保存按键。录后可点时间线「按键轨」旁的眼睛开关，或在「画面 → 键盘」换位置。按键随对应的屏幕片段移动和裁切，默认 `⌃⇧K` 清空当前键帽。选择「所有按键」时会保留实际键帽，输入敏感信息前请暂停录制。 [KeyCastr](https://github.com/keycastr/keycastr)

首次打开简录会集中显示「权限设置」。可以按需授权屏幕与系统音频录制、摄像头、麦克风和输入监控，也可以稍后从录制准备页的盾牌按钮打开。macOS 要求重开时，简录会恢复授权步骤和当时的录制开关。

## 时间线和导出

- 预览按工程画布比例显示，播放条紧贴画面下方。右侧「画面」可调片段和人像，「运镜」可调自动运镜、光标和点击，「声音」可调分轨音量。
- 多机位各有一条人像轨，可以独立裁剪、移动、隐藏和镜像。可见机位默认并排。选中机位，在右侧点「从播放头切到此机位」，从播放头到该片段结束只展示这一机位。后续可再切换或撤销。
- 拖片段中间移动，拖左右手柄裁切。点时间标尺或拖播放条移动播放头，选轨后按分割快捷键（默认 `⌘K`）。打开「自动合拢」后，删除或缩短片段时各轨会一起剪去对应时段，后面的内容同步前移。屏幕轨上与删减相连、通往下一段画面的空隙也会合拢。默认开启，已有开关设置会保留。
- 现有空隙可在素材轨的空白处点右键，选择「删除空隙并合拢各轨」。这段时间会从画面、声音和字幕中一起剪去。右键操作独立于「自动合拢」开关，可以撤销。
- 时间线默认显示全片，右侧缩放条从中间起步。「适合全片」可随时回到默认视图。鼠标放在轨道区域，按住 Ctrl 滚轮围绕指针缩放，按住 Option（Alt）滚轮横移，直接滚轮上下滚动。时间线下缘也有横移条。屏幕和人像显示各自的缩略图，系统声音、麦克风及原片声音显示实际波形。轨道左侧的眼睛和喇叭控制预览与导出的显隐或静音。
- 「更多 → 追加 MP4…」会把新画面和原片声音放到时间线末尾，再用片段编辑移动或拼接。撤销按钮可以撤回片段操作。
- 把播放头放到要开始补画面的位置，选「添加 → 添加 B-roll 视频…」导入 MP4 或 MOV。B-roll 在独立轨上覆盖原画面，解说和其他声音继续播放。拖动或裁切可以调整出场时机。重叠导入会替换同一段 B-roll，可撤销。
- 在人像轨把需要全屏的片段两端分割，右键选「此片段人像全屏」。人像会居中裁切并铺满当前 16:9 或 9:16 画布。
- 「添加 → 在播放头添加花字」会建立花字轨。右侧「画面 → 花字」可改内容、位置和颜色，拖动花字或它的两端可调时长。花字会随预览和成片一起显示。
- 「继续录制」回到录制前检查。选好画面和输入后录制，结束时新素材按轨道接到当前时间线末尾，并保留各段的光标与点击数据。可用「返回当前工程」取消续录。续录沿用当前工程的混音和人像布局。
- 「运镜」页的「点击运镜」控制点击放大、跟随与虚化，「光标」控制样式、大小、缓动和尾迹。「点击效果」可以设置波纹和点击音效，支持机械咔哒、轻触、清脆按键与短提示音，音量可调并可试听。
- 「声音」可单独调每条音轨。麦克风最高 200%，大声峰值会被柔和限制，原始收音保存在独立素材里。「应用人声优先配比」将麦克风调到至少 100%，原声降到 30% 或更低。打开「说话时自动压低原声」后，检测到人声时系统声进一步降低，说完恢复。看到麦克风信号偏弱的提示时，可静音系统声、单听麦克风轨。用耳机监听可减少外放进入麦克风。 [Apple 声音输出设置](https://support.apple.com/en-afri/guide/mac-help/-mchlp2256/mac)
- 在预览下方切换「原比例」「16:9 横屏」或「9:16 竖屏」。右侧「画面 → 画布」可选内置背景或导入图片，调整竖屏像素尺寸并单独导出底板 PNG。「录屏」和「人像」分别调宽度及中心位置，中间进度条可关闭。
- 从字幕轨导入 SRT 或 TXT，点字幕片段后在右侧改文字、时间和样式。点垃圾桶可仅删字幕，点「剪掉这句对应的时段」可同步剪掉各轨中的这一段并合拢。拖中间移动，拖两端改起止时间。SRT 沿用时间码，纯文本 TXT 会按字数分配时间，可再校准。字幕轨的眼睛控制预览和成片里的显示。
- 右侧「字幕」的「临时导出」可生成混音 M4A 或低清 MP4。按同一面板的步骤打开通义听悟，选择文件上传转写，再将下载的 SRT 或 TXT 导回字幕轨。 [通义听悟](https://tingwu.aliyun.com/)
- 工程中有字幕后，点右侧「AI 校对字幕…」，简录会直接在本机校对。确认修改建议后应用，字幕时间码保留，整批修改可一次撤销。
- 「保存工程…」保留素材和编辑设置。「导出 MP4…」可按 1080p 或 4K 上限生成横屏成片，竖屏按「画布」设定的尺寸导出。最高 30 帧/秒，使用 H.264 视频和混合 AAC 音轨。

`.desktake` 工程可以保存并重新打开。0.2 的工程打开时会把原来的裁切和时间偏移转为片段。已有 MP4 会以原片画面和原片音频导入，可以剪辑，也可以手动添加运镜焦点。镜像设置保存在工程中，只影响预览和导出时的人像方向，原始摄像头素材保留拍摄方向。

## 交给 Agent 剪辑

1. 点剪辑工作台顶部的「Agent 剪辑」，选择「生成素材包并复制提示词…」和存放位置。素材包包含分轨工程副本、`agent-context.json` 和 `AGENT.md`。
2. 在本地 Agent 中选择刚生成的文件夹，粘贴提示词并补上剪辑要求，例如「剪掉开头空等和中间的长停顿，保留实操步骤」。Agent 按包内说明生成 `agent-edit.json`。
3. 回到简录点「Agent 剪辑 → 导入剪辑方案…」。方案支持按时段删除并同步合拢各轨，应用后可撤销、预览和导出。
4. 需要继续剪辑时，在当前时间线上再次生成素材包。简录会更新同一个素材包，只补齐新增素材，不会为每一轮重新复制整段录像。

素材包在所选文件夹生成，简录通过剪贴板传递提示词。Agent 侧对媒体的读取、分析和数据处理取决于所选工具及其权限。

## 源码和构建

在装有 Xcode 的 Mac 上，从项目目录运行以下命令。本机用 Xcode 26.6 构建。

```bash
bash prepare-proofreader.sh
./build.sh
```

准备脚本会将离线校对引擎和约 1.12 GB 的模型校验后保存到 `build.noindex/ProofreaderDependencies`。完整构建将两者随 App 打包。仅构建基础版时可直接运行 `./build.sh`，没有随包模型的版本会尝试使用系统可用的 Apple Intelligence 端侧模型。

日常更新时先退出简录，再运行上面的命令。构建成功后会原位替换 `build.noindex/简录.app`，不会为每次构建新建一个版本目录；把这份 App 拖到桌面或「应用程序」覆盖旧版即可，在应用内可以查看版本号。

默认使用本机临时签名。重新构建后，如果系统设置显示「简录」已开启，但应用仍提示需要授权，请在「隐私与安全性」下找到提示对应的一项（如「输入监控」或「屏幕与系统音频录制」），移除旧条目，再用「＋」添加当前的「简录.app」。按系统提示退出并重新打开。输入监控未就绪时也能录屏，本次不会保留按键。开发时可用 `DESKTAKE_SIGN_IDENTITY` 指定固定的签名身份。 [Apple 输入监控说明](https://support.apple.com/zh-cn/guide/mac-help/mchl4cedafb6/mac) · [Apple 代码签名要求](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)

商店首发测试使用独立构建，保留 Mac 和外接设备，启用 App Sandbox。这个构建从源码编译和打包时就排除了手机网页配对及其接收组件，并使用独立的测试标识。

```bash
./build.sh --store "build.noindex/简录-商店测试.app"
```

正式提审时使用注册的 App 标识和商店发行签名。以后加入手机扫码时，随同一商店页面发布新版本，并更新网络权限、隐私说明和审核资料。 [Apple 版本更新说明](https://developer.apple.com/help/app-store-connect/update-your-app/create-a-new-version)

- `ScreenTake.swift` 用 ScreenCaptureKit 接收画面、系统声音和麦克风样本，用 AVFoundation 连接摄像头。
- `MovieWriter.swift` 将素材分别写到共享时间轴上的文件。 `PointerCapture.swift` 只在录制期间采集所选范围内的鼠标位置与点击。
- `TakeProject.swift` 存取工程，`TimelineClip.swift` 计算片段编辑，`ClipTimelineView.swift` 显示时间线。 `AudioWaveform.swift` 对音频实际解码并计算峰值。
- `MotionEffects.swift` 计算光标平滑和点击运镜，`TakeCompositor.swift` 用 Core Image 合成。 `MovieExport.swift` 组装时间线、混音并导出。
